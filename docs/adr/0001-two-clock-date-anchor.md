# 双时钟：相对日期锚定宿主时间

DSH 每轮同时注入用户宿主时间与灰泽满所在地（虚拟澳洲）时间。2026-10-29 23:35 +08 的一次排期卡把标题写成「明天」、条目写成「今天（10-30）」，因为人设卡只说「时间以注入的『灰泽满所在地』为准」，模型把她的日期当成了会话日期。现在固定：注入文本第一行是任务日期基准（宿主设备时区），相对日期、排期、提醒与截止日期按它算；她的当地日期只用于她的第一人称时间、作息与当地情况，同一张卡只用一个日期参照系；没有选择「只改人设卡」或「只注入相对日期」，因为工作会话与闲聊会话共用同一个注入面，两套时钟必须相邻出现才能压住跨日误读。

## Consequences

- 注入文本固定三行，整点粒度下同一小时内字节稳定，不增加快照条数。
- 任务日期基准取宿主设备时区；桌面端即用户所在时区，远程网页端可能与浏览器时区不一致。
- 不写「快 3 小时」这类偏移数字，跨日关系由两行日期表达，夏令时切换不需要改文案。
